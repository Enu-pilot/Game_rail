# サンプルの駅配線と出典

各サンプルの駅の配線（待避線・頭端線の本数）は、Wikipedia 各駅記事の基本情報「ホーム」（N面M線、通過線の有無）から決めています。
同じ駅に複数の事業者・路線がある場合は、その路線の事業者・路線名が一致する基本情報を使っています。

- 複線区間：線数4以上（通過線を含む）→ 上下とも待避線、3線 → 副本線1本、2線 → 待避線なし
- 単線区間（前後どちらかが単線）：線数3以上 → 副本線2本、2線 → 行き違い可（副本線1本）、1線 → 行き違い不可
- 頭端式の終着駅：線数をそのまま着発線の本数に
- 「N面M線」に通過線（ホームのない本線）が含まれない駅、並走する別路線（線路別複々線）の線路まで数えている駅、
  1本の副本線がどちら向きかは、記事本文と「のりば」表で補正（補足欄に根拠）
- ホーム構成を路線ごとに特定できなかった駅・分岐線の自線ホーム・北海道新幹線の延伸区間（未開業）は、配線略図.net を参考にした指定のまま
