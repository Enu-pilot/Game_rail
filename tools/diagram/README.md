# 配線略図からサンプルの配線データを作る

[配線略図.net](https://www.haisenryakuzu.net/)（CC BY 4.0）の配線図（SVG）を読み取り、
サンプル路線の駅の配線（本線・副本線・渡り線・シーサス・留置線・ホーム・車両基地・立体交差）を
`src/samples/data/<サンプル>.js` に書き出すスクリプトです。ゲームの実行には使いません。

1. `fetch.py` … `pages.txt` の各ページと配線図 SVG を取得（`/tmp/claude-0/hs/` に保存）
2. `parse_svg.py` … SVG を線路・ホーム・建屋・転車台・文字に分解（`parsed.json`）
3. `strip.py` … 画像を路線順につないだ「帯」を作り、本線をたどる（分岐では先まで続く側・直進側）
4. `export.py` … 帯からサンプル路線ぶんを切り出し、駅の範囲・ホームに面した線・使える向き・交差を求める
5. `build_data.py` … サンプルごとの設定（どのページのどの駅からどの駅まで、本線の選び方）で書き出す
6. `render_data.py` … 書き出したデータを絵にして確認する

作業用のパス（`/tmp/claude-0/...`）は書き換えて使ってください。
