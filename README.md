# 車両基地レイアウトデザイナー

鉄道の**車両基地（電車区・車両センター）や駅ホームのレイアウト**を、ブラウザ上で自由に設計できる Web アプリです。
線路を敷き、構造物・検修設備・信号や分岐器を配置し、**各線路の名称・留置可能両数・留置する編成**まで管理できます。

ビルド不要・依存パッケージゼロ（Canvas 2D + ES Modules のみ）。

## 起動

ES Modules を使うため `file://` では動きません。ローカルサーバ経由で開いてください。

```bash
npm start            # → http://localhost:5173/
# もしくは
python3 -m http.server 5173
```

初回起動時はサンプルレイアウト「みどりが丘車両センター」が読み込まれます。
編集内容はブラウザの localStorage に自動保存され、JSON ファイルへの書き出し／読み込みもできます。

## できること

### 線路（用途別に色分け・すべて名称を設定可能）

| 種別 | 説明 |
| --- | --- |
| 本線 / ホーム着発線 | 基地外へつながる営業線・旅客ホームに接する発着線 |
| 入区線 | 車両基地などに入区するための線路 |
| 出区線 | 車両基地などから出区するための線路 |
| 入出区線 | 入出区兼用の線路 |
| 留置線 | 車両を留置するための線路 |
| 引上線（入換線） | 入換のために引上げる線路 |
| 洗浄線 | 車両を洗浄するための線路 |
| 保守用車基地 | 各種保守用車のための線路 |
| 試運転線 | 車両の試運転に用いる線路 |
| 解体線 | 車両を解体する際に留置する線路 |
| 検修線 | 車両検査や修繕（検修）をおこなう線路 |
| 仕業検査線 / 交番検査線（交検線） / 臨時検査線（臨検線） / 転削線 | 各検査・転削のための線路 |
| 安全側線 / その他の側線 | — |

線路は折線（ポリライン）で敷設し、頂点のドラッグ・追加・削除で自由に整形できます。
延長（m）から**留置可能両数を自動算出**（自動 or 手入力に切替可）。
各線路の **A端・B端には端点種別**（開放／車止め／場外接続）を設定でき、図上に記号で描画されます。
「場外接続」にした端点は、出区経路の探索で基地の出入口として扱われます。

### 構造物・設備

- **駅設備** — ホーム（島式・相対式）、ホーム上屋、跨線橋、**階段・幅広階段・エスカレーター**、地下通路、駅舎、改札、待合室、エレベーター
- **事務所・現業機関** — 管理事務所、乗務員区、運転区、車掌区、研修センター、詰所
- **検修部門・工場** — 検修庫、車体工場、塗装場、部品職場、電機職場、台車職場、検査職場、資材倉庫、保守用車庫、**扇形庫**
- **線路まわりの設備** — **転車台**、遷車台（トラバーサー）、および最寄りの線路に自動スナップする 洗車機、検査台（ピット）、清掃台、車輪転削盤、車体ジャッキ、砂撒き装置、給油設備、給水・汚物抜取、地上給電設備
- **分岐器・信号** — ポイント（片開き／両開き／三枝）、シーサスクロッシング、渡り線、転轍機、脱線転轍器、出発／場内／閉塞／入換信号機、入換標識、車止め
  - 分岐器は**線路の結節点を示す記号**として扱います。実寸（番数・全長）は持たず、拡大率によらずほぼ一定の大きさで表示されるので、縮尺の大きい基地図でも位置と向きが読み取れます
  - 編集できるのは 種類（片開き／両開き／三枝／シーサス／渡り線／平面交差）・位置・向き・開く側・番号ラベルで、サイズ変更はありません
  - **線路が交わる点をクリックすると分岐器を自動設置**します（下記）
- **その他** — 変電所、駐車場、資材置場、フェンス、守衛所、テキストラベル

### 線路の交点をクリックして分岐器を設置

選択ツールで線路どうしが交わる点にカーソルを合わせると、その点が黄色くハイライトされます（設置済みなら水色）。
クリックすると、配線から向きを判定して分岐器を自動で設置します。

- 基準線（最も直線に近い2方向）に沿って向きを決め、**分かれていく側へ開く**ように左右も自動判定
- 分岐が2方向なら三枝ポイント、4方向以上ならシーサスクロッシングを選択
- **接続点のない交差**をクリックすると、交差角を計算して**ダイヤモンドクロッシング（平面交差）**を設置
- 設置後はプロパティで種類・交差角（平面交差）・「⇅ 開き反転」による左右反転・番号ラベルを調整できます

### 転車台

転車台は図形としてだけでなく、**経路探索のハブ**として機能します。

- 転車台の円内（半径＋余裕）に端点がある線路は、すべて転車台を介して互いにつながっているものとして扱われます
- 転車台を通る進路は**転向角の制限を受けず**、どの放射線へも転回できます（経路結果に「転車台で転回」と転車回数を表示）
- **桁長より長い編成は載らない**ため警告します（機関車単体・単車の入換向け）
- プロパティで直径を数値入力できます。扇形庫は外径Wと回転で向きを合わせて配置します

### 進路（連動）と信号現示

分岐器は**結節点でどの方向が開通しているか**の状態を持ちます。

- 接続点で成立しうる進路（開通パターン）を配線から自動的に列挙し、**定位／反位**として選択できます
  （プロパティのセレクトかボタンで転換。図上では開通側が明るく表示され、定位＝緑・反位＝黄）
- 平面交差（ダイヤモンドクロッシング）は転換せず、常時両方向が開通しているものとして扱います

信号機・入換標識は**線路に紐づき、防護する進行方向**（A端→B端／B端→A端）を持ちます。

**進路の構成**

1. 経路を探索すると、通過する各分岐器に**必要な開通方向**が一覧表示されます
2. 「⇄ この区間の分岐器を転換」で一括転換、「進路を構成」で進路として登録します
3. 折返しを挟む経路は、実際の入換と同じく**区間ごとの進路**に分割されます
   （同じ分岐器を途中で転換するため、同時には構成できません）
4. 構成済みの進路は一覧から**構成／解除**でき、解除→次の進路を構成、と順に動かせます
5. 進路の入口になっている信号機が**進行（入換信号機なら入換進行）**を現示します。
   進路内に在線があれば**注意**、分岐器が進路どおりでなければ**停止**のままです
6. 既に構成されている進路と**分岐器の開通方向・線路区間が競合**する進路は構成できません

経路探索の「**現在の分岐器の開通方向に従う**」を有効にすると、いまの開通状態のまま進める経路だけを探索します
（例：8号が1番線側に開通していると、2番線からの経路は見つかりません）。

### 閉塞区間と現示の連鎖

信号機の内方は**閉塞区間**として追跡されます。区間は「構成中の進路 →（なければ）分岐器の開通方向 →（分岐器がなければ）最も直進に近い方向」をたどり、
次の同じ向きの信号機・車止め・場外・未開通の分岐器のいずれかで終わります。

- 区間内に在線（留置編成）があれば **停止**
- 次の信号機が停止なら **注意**、注意なら **減速**（4灯以上の信号機のみ。3灯は進行）、それ以外は **進行**
- 閉塞信号機は自動信号として扱い、進路がなくても区間の状態だけで現示します
  （出発・場内・入換信号機は進路が構成されていなければ停止）
- 信号機を選択すると、その閉塞区間が図上に帯で表示されます

### 同時入線の効率（経路タブ）

起点（既定は場外接続のある線路）から各留置線への経路を一括で求め、**同時に構成できる進路の最大本数**を算出します。

- 分岐器と線路区間を共用しない進路の最大の組み合わせ（最大独立集合）を厳密に探索
- **並列度**（同時本数 ÷ 経路のある線数）、平均走行距離・折返し回数・所要時間
- 多くの進路が共用する**ボトルネック**（分岐器・線路）を上位から表示
- 全編成を捌くのに必要な回数と所要時間の目安（入換速度・折返し時間から算出）
- 入区／出区の方向を切り替えて評価できます

### 入換シミュレーション（運転タブ）

「編成 → 行先」の移動を計画に並べ、時間軸で実行します。

- 移動ごとに経路を探索し、**折返しで区切られた区間ごとに進路を構成 → 分岐器を転換 → 走行 → 折返し**を自動で進めます
- 走行中の列車は図上を移動し、進路の帯・分岐器の開通方向・**信号現示がリアルタイムに連動**します
- 進路が他の進路と競合する場合は「進路待ち」で停止し、解除されると再開します
- 再生速度（×1〜×32）、入換速度（km/h）、折返し時間、進路構成の所要時間を設定できます
- 実行ログに時刻つきで進路構成・折返し・到着が記録されます

### 入換経路の検証（経路タブ）

線路の端点どうし・端点と他線の途中が近接していれば自動的に「接続」と判定し、基地全体の接続グラフを構築します。

- 対象編成（または両数）・起点・着点を選ぶと、**折返し回数が最小になる入換経路**を探索して図上にハイライト
- 着点には「◎ 場外へ出区（出入口）」も選べます
- 分岐の向きを考慮し、転向角が設定値（既定 90°）を超える進路は**折返しが必要**と判定
- 「現在の分岐器の開通方向に従う」を有効にすると、転換なしで進める経路だけを探索
- 折返しに使う線路の**有効長が編成長に足りない場合は警告**（引上線の長さ検証）
- 経由する線路に他編成が留置されていれば「支障」として警告、着点の留置可能両数超過も警告

### レイアウト検証

経路タブ下部に、レイアウトの不具合を一覧表示します（図上には赤／橙のマーカー、クリックでその場所へジャンプ）。

- どの線路にも接続していない**孤立した線路**
- 車止めも場外接続も設定されていない**未処理の端点**
- **場外（出入口）から到達できない線路**
- **線路中心間隔の不足**（既定 4.0m、設定で変更可）
- **接続点のない線路どうしの交差**（分岐器・クロッシングの不足）
- **建築限界の支障**（既定 片側 1.9m の範囲に建屋・ホーム・駐車場などが掛かっている）
- **構造物どうしの重なり**
- 留置両数が有効長を超えている線路

なお、プロパティの数値欄は入力中にパネルを作り直さないため、幅・奥行・直径・座標などを
キーボードでそのまま打ち直せます（小数も可）。

### 車両と編成

編成には**車種**を設定できます。車種ごとに標準の1両長と色・記号を持ちます。

| 車種 | 標準1両長 | 図上の表現 |
| --- | --- | --- |
| 電車（EMU） | 20m | パンタグラフ記号 |
| 気動車（DC） | 20m | 排気記号 |
| 客車 | 20m | 付随車（動力表現なし） |
| 貨車 | 14m | 付随車（動力表現なし） |
| 電気機関車（EL） | 18m | パンタ2基＋「EL」 |
| ディーゼル機関車（DL） | 16m | 排気＋「DL」 |
| 蒸気機関車（SL） | 20m | 煙突＋「SL」 |
| 保守用車 | 12m | 排気記号 |

- 客車・貨車などには**牽引機（EL／DL／SL、最大3両）**を付けられます。編成長・両数は牽引機を含めて計算されます
- 拡大すると1両ずつ描き分けられ、機関車は車体色と記号で区別できます
- 「＋ 電車／気動車/客車列車／貨物列車／機関車／保守用車」のボタンから、既定の構成で編成を追加できます

### 留置両数と編成

- 線路ごとに **留置可能両数**（自動算出 or 手入力）・**1両長の個別設定**
- **編成**を作成し、車種・両数・牽引機・形式・色・メモを編集、任意の線路へ割り当て
- 留置した編成は線路上に**車両1両ずつの帯**として描画され、有効長の超過は赤く警告（車種ごとに1両長が異なるため、超過判定は実長で行います）
- 「自動で留置線へ割付」で未留置編成を空き線に一括割当
- 基地全体の留置可能両数・留置中両数・使用率をサマリー表示

## 操作方法

| 操作 | 内容 |
| --- | --- |
| パレット → 線路種別 → クリック | 折線で線路を敷設（ダブルクリック／Enter／右クリックで確定） |
| パレット → 構造物 → クリック | 構造物を配置（Shift+クリックで連続配置） |
| ドラッグ | 選択中の線路・構造物を移動（空白部分のドラッグは画面移動） |
| ホイール | ズーム |
| 選択中の線路をダブルクリック | 折点を追加／折点上でダブルクリックすると削除 |
| 選択中の構造物の四隅をドラッグ | サイズ変更（Shiftで縦横比固定、Altでスナップ解除。分岐器は記号のため対象外） |
| 線路の交点をクリック | 分岐器（未接続の交差ならダイヤモンドクロッシング）を自動設置 |

ショートカット: `V` 選択 / `T` 線路 / `H` 画面移動 / `R` 45°回転 / `F` 全体表示 / `G` グリッド /
`Enter` 敷設確定 / `Esc` 取消 / `Delete` 削除 / `Ctrl+Z` 元に戻す / `Ctrl+Shift+Z` やり直し /
`Ctrl+D` 複製 / `Ctrl+S` JSON保存 / `Ctrl+O` 読込 / スペース+ドラッグ 画面移動

設定タブでグリッド間隔（既定 5m）、標準1両長（既定 20m）、線路端部の余裕長（既定 10m）、
線路中心間隔の最小値（既定 4.0m）、建築限界の片側幅（既定 1.9m）、転向角の上限（既定 90°）、
接続点・検証マーカーの表示、スナップや 45° 拘束の ON/OFF を変更できます。

## データ形式（JSON）

```jsonc
{
  "name": "みどりが丘車両センター",
  "settings": { "gridM": 5, "carLengthM": 20, "clearanceM": 10 },
  "tracks":     [{ "id": "t_…", "name": "3番線", "kind": "stabling",
                   "points": [{"x":340,"y":302},{"x":676,"y":302}],
                   "capacityMode": "auto", "capacity": 0, "carLengthM": null,
                   "ends": { "a": "buffer", "b": "open" } }],
  "objects":    [{ "id": "b_…", "type": "turnout_single", "x": 676, "y": 302,
                   "w": 12, "h": 5, "rot": 1.87, "mirror": true,
                   "position": 1, "trackId": null },
                 { "id": "b_…", "type": "signal_shunt", "x": 660, "y": 302,
                   "dir": "ab", "trackId": "t_…" }],
  "routes":     [{ "id": "r_…", "name": "入換1: 1番線 → 引上線",
                   "fromTrackId": "t_…", "toTrackId": "t_…",
                   "path": [{ "trackId": "t_…", "fromAt": 0, "toAt": 120 }],
                   "turnouts": [{ "objectId": "b_…", "index": 1, "name": "反位" }],
                   "signalId": "b_…", "set": true }],
  "formations": [{ "id": "f_…", "name": "12系客車", "series": "12系",
                   "vehicle": "coach", "cars": 5, "carLengthM": null,
                   "loco": { "type": "dl", "count": 1 },
                   "color": "#b5654a", "trackId": "t_…" }]

```

座標・寸法の単位はすべてメートルです。分岐器（`shape: "turnout"`）の `w` / `h` は
当たり判定の目安で、描画は画面上一定サイズの記号として行われます。
