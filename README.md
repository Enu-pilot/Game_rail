# 車両基地レイアウトデザイナー

鉄道の**車両基地（電車区・車両センター）や駅・本線のレイアウト**を、ブラウザ上で自由に設計できる Web アプリです。
線路を敷き、構造物・検修設備・信号や分岐器を配置し、**各線路の名称・留置可能両数・留置する編成**、
さらに**進路（連動）・信号現示・入換シミュレーション・ダイヤグラム**まで扱えます。

さらに、駅ごとの人口から**需要を発生させて混雑率・積み残し・運賃収入・収支**を評価する
**経営シミュレーション**まで含んだ、実践型の鉄道経営ゲームとして遊べます。

画面上部で **配線図** と **ダイヤ** の2つのモードを切り替えて使います。

ビルド不要・依存パッケージゼロ（Canvas 2D + ES Modules のみ）。

## 起動

ES Modules を使うため `file://` では動きません。ローカルサーバ経由で開いてください。

```bash
npm start            # → http://localhost:5173/
# もしくは
python3 -m http.server 5173
```

初回起動時はサンプルレイアウト「みどりが丘車両センター」が読み込まれます。
編集内容はブラウザの localStorage に自動保存され、JSON ファイルへの書き出し／読み込みもできます。

## できること

### 線路（用途別に色分け・すべて名称を設定可能）

| 種別 | 説明 |
| --- | --- |
| 本線 / ホーム着発線 | 基地外へつながる営業線・旅客ホームに接する発着線 |
| 入区線 | 車両基地などに入区するための線路 |
| 出区線 | 車両基地などから出区するための線路 |
| 入出区線 | 入出区兼用の線路 |
| 留置線 | 車両を留置するための線路 |
| 引上線（入換線） | 入換のために引上げる線路 |
| 洗浄線 | 車両を洗浄するための線路 |
| 保守用車基地 | 各種保守用車のための線路 |
| 試運転線 | 車両の試運転に用いる線路 |
| 解体線 | 車両を解体する際に留置する線路 |
| 検修線 | 車両検査や修繕（検修）をおこなう線路 |
| 仕業検査線 / 交番検査線（交検線） / 臨時検査線（臨検線） / 転削線 | 各検査・転削のための線路 |
| 安全側線 / その他の側線 | — |

線路は折線（ポリライン）で敷設し、頂点のドラッグ・追加・削除で自由に整形できます。
延長（m）から**留置可能両数を自動算出**（自動 or 手入力に切替可）。
各線路の **A端・B端には端点種別**（開放／車止め／場外接続）を設定でき、図上に記号で描画されます。
「場外接続」にした端点は、出区経路の探索で基地の出入口として扱われます。

### 構造物・設備

- **駅設備** — **駅（停車場マーカー：ダイヤの駅になります）**、ホーム（島式・相対式）、ホーム上屋、跨線橋、**階段・幅広階段・エスカレーター**、地下通路、駅舎、改札、待合室、エレベーター
- **事務所・現業機関** — 管理事務所、乗務員区、運転区、車掌区、研修センター、詰所
- **検修部門・工場** — 検修庫、車体工場、塗装場、部品職場、電機職場、台車職場、検査職場、資材倉庫、保守用車庫、**扇形庫**
- **線路まわりの設備** — **転車台**、遷車台（トラバーサー）、および最寄りの線路に自動スナップする 洗車機、検査台（ピット）、清掃台、車輪転削盤、車体ジャッキ、砂撒き装置、給油設備、給水・汚物抜取、地上給電設備
- **分岐器・信号** — ポイント（片開き／両開き／三枝）、ダイヤモンドクロッシング、シングル／ダブルスリップ、転轍機、脱線転轍器、出発／場内／閉塞／入換信号機、入換標識、**速度制限標**、車止め
  （渡り線・シーサスクロッシングは2線にまたがる装置なので、点としては置かず配線から判定します）
  - 分岐器は**線路の結節点を示す記号**として扱います。実寸（番数・全長）は持たず、拡大率によらずほぼ一定の大きさで表示されるので、縮尺の大きい基地図でも位置と向きが読み取れます
  - 編集できるのは 種類（片開き／両開き／三枝／平面交差／シングルスリップ／ダブルスリップ）・位置・向き・開く側・番号ラベルで、サイズ変更はありません
  - **線路が交わる点をクリックすると分岐器を自動設置**します（下記）
- **その他** — 変電所、駐車場、資材置場、フェンス、守衛所、テキストラベル

### 線路の交点をクリックして分岐器を設置

選択ツールで線路どうしが交わる点にカーソルを合わせると、その点が黄色くハイライトされます（設置済みなら水色）。
クリックすると、配線から向きを判定して分岐器を自動で設置します。

- 基準線（最も直線に近い2方向）に沿って向きを決め、**分かれていく側へ開く**ように左右も自動判定
- 分岐が2方向なら三枝ポイント、直線の組が2組ある交差なら平面交差を選択
- **接続点のない交差**をクリックすると、交差角を計算して**ダイヤモンドクロッシング（平面交差）**を設置（パレットでスリップを選んでおけばスリップになります）
- 設置後はプロパティで種類・交差角（平面交差）・「⇅ 開き反転」による左右反転・番号ラベルを調整できます

### 渡り線・シーサスクロッシング（2線にまたがる装置）

シーサスクロッシング（両渡り線）は**隣り合う2本の線路にまたがって設置する装置**なので、1点の記号では表せません。
このアプリでは**線路のつながりから装置として判定**します。

- 2本の線路を結ぶ短い線路（140m以下・取り付く2線がほぼ平行）を**渡り線**とみなします
- 同じ2線を結ぶ渡り線が**互いに交差**していれば**シーサスクロッシング**
  （転てつ器4・ダイヤモンドクロッシング1）として1つの装置にまとめます
- 図上では4つの接続点を囲う枠と、中央のダイヤモンドの印で表示します（点ではなく範囲）
- 装置の中の交差は正規のダイヤモンドなので、「接続点なしで交差」や線路中心間隔の支障には数えません
- **2つの渡り線は同時に使えません**。別々の渡り線を通る進路は「シーサスのダイヤモンドを共用」として競合します
- 経路タブの「分岐器・交差の装置」に、検出した渡り線・シーサスが一覧で出ます

パレットからは点の記号として置けないようにしてあります（配線を描けば自動で装置として認識されます）。

### 斜めの交差点に置ける装置

線路が斜めに交差する点をクリックすると、3種類の装置を設置できます。
パレットの「分岐器・信号」で種類を選んでから交点をクリックすると、その種類で設置されます。

| 装置 | つながり | 開通方向 |
|---|---|---|
| ダイヤモンドクロッシング | 交差するだけ（渡れない） | 直進2方向のみ・転換しない |
| シングルスリップ | 片側にトング | 直進2＋渡り1の**3方向** |
| ダブルスリップ | 両側にトング | 直進2＋渡り2の**4方向** |

- スリップを置くと、交差部で**2本の線路が実際につながり**、入換経路が通れるようになります
- ダイヤモンドは直進しか通れません（経路探索でも渡れません）
- 交差部に装置を置けば「接続点なしで交差」の支障は解消します
- 開通方向はプロパティの「開通方向」で切り替えられ、進路（連動）の判定にも反映されます

### 転車台

転車台は図形としてだけでなく、**経路探索のハブ**として機能します。

- 転車台の円内（半径＋余裕）に端点がある線路は、すべて転車台を介して互いにつながっているものとして扱われます
- 転車台を通る進路は**転向角の制限を受けず**、どの放射線へも転回できます（経路結果に「転車台で転回」と転車回数を表示）
- **桁長より長い編成は載らない**ため警告します（機関車単体・単車の入換向け）
- プロパティで直径を数値入力できます。扇形庫は外径Wと回転で向きを合わせて配置します

### 進路（連動）と信号現示

分岐器は**結節点でどの方向が開通しているか**の状態を持ちます。

- 接続点で成立しうる進路（開通パターン）を配線から自動的に列挙し、**定位／反位**として選択できます
  （プロパティのセレクトかボタンで転換。図上では開通側が明るく表示され、定位＝緑・反位＝黄）
- 平面交差（ダイヤモンドクロッシング）は転換せず、**直進の2方向だけ**が開通しているものとして扱います（渡れません）

信号機・入換標識は**線路に紐づき、防護する進行方向**（A端→B端／B端→A端）を持ちます。

**進路の構成**

1. 経路を探索すると、通過する各分岐器に**必要な開通方向**が一覧表示されます
2. 「⇄ この区間の分岐器を転換」で一括転換、「進路を構成」で進路として登録します
3. 折返しを挟む経路は、実際の入換と同じく**区間ごとの進路**に分割されます
   （同じ分岐器を途中で転換するため、同時には構成できません）
4. 構成済みの進路は一覧から**構成／解除**でき、解除→次の進路を構成、と順に動かせます
5. 進路の入口になっている信号機が**進行（入換信号機なら入換進行）**を現示します。
   進路内に在線があれば**注意**、分岐器が進路どおりでなければ**停止**のままです
6. 既に構成されている進路と**分岐器の開通方向・線路区間が競合**する進路は構成できません

経路探索の「**現在の分岐器の開通方向に従う**」を有効にすると、いまの開通状態のまま進める経路だけを探索します
（例：8号が1番線側に開通していると、2番線からの経路は見つかりません）。

### 閉塞区間と現示の連鎖

信号機の内方は**閉塞区間**として追跡されます。区間は「構成中の進路 →（なければ）分岐器の開通方向 →（分岐器がなければ）最も直進に近い方向」をたどり、
次の同じ向きの信号機・車止め・場外・未開通の分岐器のいずれかで終わります。

- 区間内に在線（留置編成）があれば **停止**
- 次の信号機が停止なら **注意**、注意なら **減速**（4灯以上の信号機のみ。3灯は進行）、それ以外は **進行**
- 閉塞信号機は自動信号として扱い、進路がなくても区間の状態だけで現示します
  （出発・場内・入換信号機は進路が構成されていなければ停止）
- 信号機を選択すると、その閉塞区間が図上に帯で表示されます

### 同時入線の効率（経路タブ）

起点（既定は場外接続のある線路）から各留置線への経路を一括で求め、**同時に構成できる進路の最大本数**を算出します。

- 分岐器と線路区間を共用しない進路の最大の組み合わせ（最大独立集合）を厳密に探索
- **並列度**（同時本数 ÷ 経路のある線数）、平均走行距離・折返し回数・所要時間
- 多くの進路が共用する**ボトルネック**（分岐器・線路）を上位から表示
- 全編成を捌くのに必要な回数と所要時間の目安（入換速度・折返し時間から算出）
- 入区／出区の方向を切り替えて評価できます

### 本線と駅・ダイヤグラム（ダイヤモード）

車両基地だけでなく、**本線に駅を並べて路線を作り、ダイヤ（列車運行図表）を引く**ことができます。

1. 配線図で本線を敷き、パレットの **「駅（停車場）」** を線路上に置いて駅名を付けます
   （交換設備のある中間駅は、本線から分岐する着発線＋ホームで表現できます）
2. ダイヤタブで **路線**を作り、置いた駅を順に追加します。**駅間のキロ程は配線から自動計算**されます
3. 「＋ 普通／快速／急行／特急／回送」で列車を追加すると、表定速度と停車時分から時刻が計算され、スジが引かれます
4. 上部の **ダイヤ** ボタンで運行図表に切り替わります（横軸=時刻、縦軸=キロ程）
   - ホイールで時間軸、Shift+ホイールで距離軸を拡大縮小、ドラッグで移動
   - **スジをクリックで選択、左右にドラッグすると発時刻を変更**（1分刻み、Altで1秒刻み）
   - 列車ごとに番号・種別・始発/終着・発時刻・表定速度・停車時分を編集できます
5. **単線／複線**は路線全体の既定に加えて駅間ごとに指定でき、行き違いできない区間・追い越し・時隔不足を検出します（「単線・複線と行き違い」「待避と緩急接続」を参照）
6. 選択した列車は「▶ 運転に送る」で入換シミュレーションの計画に追加でき、実際の配線上を走らせられます
7. 運転タブを **ダイヤ運転** にすれば、ダイヤの時刻どおりに全列車が自動で走ります

### 相互直通運転と保安装置（ダイヤタブ・運用タブ）

複数の事業者が乗り入れる**相互直通運転**と、その制約を扱えます。

**事業者と直通先**
- `事業者`（自社＋乗り入れ相手）を持ち、自社線には**必要な保安装置**とホーム有効長（最大両数）を設定します
- `直通先`は他社線を表し、事業者・保安装置・最大両数・キロ程・所要時分・1日の直通客を持ちます
- 直通先は**経由**を指定でき、「自社線 → 地下鉄 → その先の私鉄」のような2社またぎの直通も表現できます

**保安装置による乗入れ可否**
- 編成ごとに **ATS-S形／ATS-P／ATC／CS-ATC／D-ATC／ATACS・CBTC／TASC／デジタル列車無線** の搭載を設定します
- 運用（行路）に含まれる列車の行き先から、その運用に必要な装置と最大両数が決まります
- 装置が足りない編成・両数が超える編成はその運用に入れられません。運用タブの**乗入れ可否**（編成×他社線の○×表）と、
  充当できない運用の理由（「CS-ATC 未搭載」「乗入れ先の最大 6 両を超える」など）が出ます
- 1つの運用は1編成が通しで担当するので、**両数と乗入れ制限が両立しない列車どうしは同じ運用に組めません**

**直通は車両運用を長くする**
- 直通する列車は、他社線を往復するあいだ編成が戻ってきません（所要時分×2＋折返し）
- そのぶん必要な編成数が増え、走行キロも増えます
- 最終列車が直通の運用は、**相手の基地で夜間滞泊**します

**直通の車両使用料（キロ精算）**
- 自社車両が他社線を走った車両キロと、他社車両が自社線を走った車両キロの差を精算します（既定 60円/車両km）
- 収支の「直通の車両使用料」に出ます。送り出すほど支払いが増え、乗り入れてもらうほど受け取りが増えます

**運転整理の縛り**
- **直通中止**：ボタンひとつで直通を打ち切ります。該当列車は境界駅で折返し、必要な保安装置の条件が消え、
  直通客（境界駅の需要）も消えます。運用数も減ります
- **直通先の遅れ**：分単位で遅れを設定して「ダイヤに反映」すると、
  直通から戻る編成の遅れが**同じ運用の次の列車へ波及**し、他社車両の列車にも遅れが乗ります
- 遅れを入れるとダイヤに支障が出るので、「行き違い・待避を自動調整」で捌きます。
  「平常ダイヤに戻す」で遅れを消し、待避も引き直します

サンプルは6社（みどり電鉄・さくら地下鉄・かえで鉄道・しらかば電鉄・みなと高速鉄道・あおば急行）の直通で、
さくら線（CS-ATC）経由でかえで本線・しらかば線（ATS-P）へ、海岸からみなと線（ATC・8両）・あおば線（6両）へ乗り入れます。
あおば線は6両までなので、6両で ATS-P を積む K11・K12 編成しか入れません。

### 車両運用と検査期限（運用タブ）

ダイヤの列車を「終着駅＝次の始発駅」でつないで**1日の運用（行路）**を組み、必要な編成数を出します。

- 折返しは「折返し時分＋3分」以上あいた列車どうしをつなぎ、**先着順**（いちばん長く待っている運用から使う）で
  組むので、**そのダイヤを回すのに必要な最小の編成数**が求まります
- 使える編成は旅客用（電車・気動車・客車）のうち、**検査線に入っていないもの**です
- 運用ごとに走行キロが出るので、編成別の**日走行キロ**が決まります
- 1日の途中で両数が変わる運用（増解結が必要）と、**夜間滞泊**（運用の終着駅ごとの本数）も出します
  滞泊が駅の番線＋近くの留置線を超えると警告します

**検査の期限**

| 検査 | 周期 | 所要 |
|---|---|---|
| 仕業検査 | 3日 | 3時間 |
| 交番検査 | 90日 または 3万km | 1日 |
| 重要部検査 | 4年 または 60万km | 8日 |
| 全般検査 | 8年 | 16日 |

- 編成ごとに前回検査からの**経過日数と走行キロ**を持ち、日走行キロから**期限までの残り日数**を出します
- 年度を進めると走行と日数が溜まり、期限の来た検査が実施されます（上位の検査は下位を兼ねます）
- **検修設備の能力**は「検査の所要時間 ÷ 周期」の合計＝常時必要な線数として、配線にある検査線と比べます
- 検査費は日々の費用に「検査費」として計上されます（走行キロ分＋日数分）

編成を増やせば混雑は下がりますが、検査線と留置線が足りなくなり、設備投資が必要になります。
**ダイヤ → 運用 → 検修設備 → 設備投資 → 長期経営** が一本につながっています。

### 経営シミュレーション（経営タブ）

駅の人口から需要をつくり、引いたダイヤで**運びきれているか**を判定します。

**需要のモデル**
- 駅ごとに **駅勢圏人口・就業/集客力・駅の性格**（住宅地／住宅＋商業／都心・ターミナル／オフィス街／学園都市／観光地）を設定
- 性格ごとの時間帯分布（住宅地は朝に発生、都心は夕方に発生）と、時間帯で変わる目的地の魅力
  （朝は就業地へ、夕方は住宅地へ）、距離による減衰から **時間帯別のOD（出発地→目的地）流動**を生成

**乗車シミュレーション**
- 1分きざみで乗客を発生させ、到着した列車に**先着順**で乗せます
- 定員（既定 140人/両）× 乗車率の上限（既定 200%）を超えると**積み残し**になり、次の列車を待ちます
- 区間ごと・時間帯ごとの **混雑率**（乗車人員 ÷ 定員）と、そのピーク時刻・列車を記録します

**経営**
- 運賃収入 = 乗車人員 × 距離制運賃（初乗り＋km加算、上限あり）
- 費用 = 運行費（車両キロ）＋ 車両費（保有両数）＋ 線路保守（営業キロ）＋ 駅運営（駅数）＋ 車両基地（線数）
- **損益・営業係数**（費用 ÷ 収入 × 100）を1日あたりで表示し、費用の内訳も出します

**評価（ゲームの目標）**
- ピーク混雑率が目標以下（既定 180%）／積み残しゼロ／黒字（営業係数 100 未満）／平均待ち時間が目標以下（既定 8分）
- 達成度を 0〜100 点で表示します

列車を増やす・両数を増やすと混雑率と積み残しは下がりますが、運行費と車両費が増えて営業係数が悪化します。
ダイヤ・編成・配線（駅の番線や留置能力）をいじりながら、**輸送と採算の両立**を探すのがこのゲームの本体です。

### 単線・複線・複々線と行き違い（ダイヤタブ）

路線全体の既定に加えて、**駅間ごとに単線／複線／複々線**を指定できます。
複々線では各停・準急が緩行線、それより速い列車が急行線を走り、互いに待避しなくてよくなります。

- 単線区間はダイヤグラム上に橙色の帯で表示されます
- **行き違い・待避ができる駅**は、配線図で発着線（番線）が2本以上ある駅です。駅名の横に緑の点が付きます
- 単線区間では対向列車が抜けるまで1列車しか入れません。支障は「ダイヤの支障」として一覧に出ます

### 待避と緩急接続（ダイヤタブ）

「**▶ 行き違い・待避を自動調整**」を押すと、発時刻の早い順に運転整理をおこない、駅ごとの待ち時間を挿入します。

- **行き違い（単線）**：対向列車が待つ駅に着くまで、手前の交換可能駅で待ちます（どちらを待たせるかは待ち時間の短い方・優等列車を優先）
- **待避（複線）**：優等列車に追いつかれる列車を、手前の待避可能駅で待たせます。
  通過駅で待つ場合は客扱いのない**運転停車**（ダイヤグラム上は破線）になります
- 待避線のない駅の中での追い越し・続行も支障として見つけ、手前の駅で待たせます
- 番線は駅ごとに時刻順で割り当て直します（待つ列車は進行方向左側の副本線、通過する列車は本線）
- 交換・待避できる駅が足りない場合は、解消できない支障として理由付きで一覧に出ます

**緩急接続**は、待避のときに普通から優等列車へ乗り換えられる組み合わせです。
乗換時間と「終着まで何分早いか」を計算して一覧にします。
待避は「待たされる」だけでなく、**先へ急ぐ乗客にとっては速達手段**になります。

ダイヤグラムでは、待ち時間が白い横線で表示されます（破線＝運転停車）。

### 連結・分離（併結運転）と機回し（ダイヤタブ）

- 列車の設定で「**併結する列車**」を選ぶと、付属編成としてその列車に連結して走ります。時刻は相手の列車に従い、
  途中駅での**連結**（既定3分）・**切り離し**（既定2分）の作業時間を相手の列車の停車に加えます。
  ダイヤグラムでは付属編成を破線で描き、連結駅に「併」、切り離し駅に「分」の印を付けます
- 付属編成は行き違い・待避の計画では相手の列車と一体で扱い、需要計算では相手の列車の定員に両数を足します
- 「**機関車牽引**」の列車は、折り返す駅で機関車を反対側へ付け替える**機回し**（既定10分）が要ります。
  運用はその時間を空けてつながれ、機回しできない駅（両端のつながった線が2本以上ないか、機回し線がない駅）では折り返せません。
  近くに転車台があれば、機関車の向きも変えられることを表示します
- 併結の誤り（相手がいない・向きが逆・区間の外・ホーム有効長を超える）は「連結・分離・機回し」の欄に出ます

### 長期戦略（経営タブ・年度決算）

1日の収支だけでなく、**年度を積み重ねて会社を育てる**長期戦略の層があります。

**年度を進める**
- 「▶ ◯年目を終えて決算する」を押すと 1 年が経過します
- 年間の収入・費用は 1日あたりの結果 × 営業日換算（既定 340日）
- 支払利息（借入残高 × 年利、既定 2.0%）を差し引きます
- **設備投資**は「前年度末からの増設分」に対して自動計上されます
  （線路 18億/km・駅 25億・車両 1.6億/両・基地の側線 2.5億/線・建物 1.2億/棟）
- 結果は現金に反映され、年度ごとの決算が履歴（表とグラフ）に残ります

**沿線人口の成長**
サービス水準に応じて、翌年の沿線人口・就業人口が増減します。

| 条件 | 成長率への影響 |
|---|---|
| ピーク混雑率 150% 以下 | +0.5% |
| 〃 180〜200% | −0.6% |
| 〃 200% 超 | −1.5% |
| 平均待ち時間 6分以下 | +0.5% |
| 〃 10分超 | −0.5% |
| 5km 運賃が 190円以下 | +0.4% |
| 〃 260円以上 | −0.4% |
| 積み残しが輸送人員の 1% 超 | −0.5% |
| 景気（イベント） | ±0.6%（年々薄れます） |

住宅地は人口が、都心・オフィス街は就業人口が伸びやすく設定されています。

**できごと（毎年ランダム）**
好景気／景気後退／沿線で住宅開発／オフィス進出／大学が開校／台風被害（復旧費）／競合路線の開業／平穏な1年。
同じレイアウトなら同じ順で起こります（年度をシードにした擬似乱数）。

**資金調達**
- 金額を入れて「借入」で現金を増やせます（限度額 既定 300億円）。借りた分は毎年の利息になります
- 「返済」で借入残高を減らせます

**目標**
純資産（現金 − 借入）が目標額（既定 400億円）に届けば達成です。
増発・増結で混雑を抑えれば沿線人口が伸びて収入が増え、そのための車両・線路・駅は設備投資として現金を減らします。
**いつ投資し、いつ回収するか**を組み立てるのが長期戦略のゲーム性です。

### 速度制限と走行計算（運転曲線）

所要時間は表定速度の割り算ではなく、**区間ごとの速度制限＋加減速による走行計算**で求めます。

速度の上限は次の4つから決まります。

| 種類 | 設定場所 | 既定 |
| --- | --- | --- |
| 線路の最高速度 | 線路のプロパティ（空欄なら全体設定） | 100 km/h |
| 速度制限標 | パレットの「速度制限標」を線路上に置き、制限速度と区間長を指定 | 45 km/h・200m |
| 分岐器の分岐側制限 | 分岐器のプロパティ（空欄なら全体設定）。**反位（分岐側）を通るときだけ**適用 | 35 km/h |
| 車両の最高速度 | ダイヤの列車ごと（種別の既定値） | 普通60／快速80／急行85／特急100 |

これらから距離ごとの上限をつくり、**減速の制約（後ろ向き）→ 加速の制約（前向き）**の順にかけて速度曲線を作り、
時間を積分します（加速度・減速度は設定タブで変更可）。

- ダイヤの各駅の着発時刻がこの計算で決まります（停車表に区間の最高到達速度も表示）
- 運転シミュレーションは同じ曲線に沿って**加速・定速・減速**しながら走ります（走行中の速度を表示）
- 同時入線の効率解析の所要時間も走行計算になります
- 省略した駅間は、その前後の制限速度を引き継いで走ります

### 駅間の省略（配線図を短く描く）

本線を実距離で描くと図が横に長くなりすぎるため、**駅間を省略して描く**ことができます。

- パレットの **「駅間省略（キロ程補正）」** を線路上に置き、省略する距離（km）を設定します
- 配線図には「≈ 1.4 km 省略」の break 記号が入り、**図は短いまま**になります
- 一方で、**ダイヤのキロ程・所要時間・経路距離・入線効率の解析には省略した距離が加算**されます
- 運転シミュレーションでは、この記号の位置で省略した距離ぶんの時間だけ走ります（「省略区間を走行中」）

サンプルでは本線を 3.45km ぶんだけ描き、5か所の省略（3.2 + 2.8 + 4.2 + 3.2 + 4.6 km）を入れて、
ダイヤ上は 21.45 km・6駅の路線として扱っています。

サンプルのダイヤは平日パターン（ラッシュは普通10両を10分ごと、日中は普通＋その5分後に快速を20分ごと、209本/日）。
快速は桜台・中原を通過し、**みどりが丘・東川で普通を追い越す**ので、待避と緩急接続がそのまま観察できます。
読み込み時に行き違い・待避の自動調整（待避72件・接続72組）を済ませた状態で始まります。

6駅の人口 24.7万人に相互直通の乗り入れ客を加えて 1日約 11.3万人を輸送し、
営業係数 85・ピーク混雑率 133%・積み残し約 400人。
このダイヤを回すのに **14運用**が必要で、8両編成を14本（うち1本は交番検査中）と6両編成2本を用意してあります。

### 配線とダイヤの連携

配線図で作った線路が、そのままダイヤの番線・留置能力になります。

- **駅の番線（発着線）**：駅マーカーのプロパティで、その駅に属する線路を登録します
  （「近くの線路から自動設定」で、90m以内の本線・着発線などをまとめて設定できます）
- **列車の発着番線**：列車ごとに各停車駅の番線を選べます（東川のような交換駅で、下りは本線・上りは1番線など）
- **番線の需給チェック**：各駅で同時に必要な番線数のピークと、配線上の番線数を並べて表示し、
  足りない駅を警告します。同じ番線を二重に使う列車も検出します
- **留置の需給チェック**：ダイヤで「終着後に入庫する」と指定した列車の本数・両数と、
  配線上の留置線の本数・空き容量を突き合わせ、不足していれば警告します
- 入庫先に指定した留置線へは、ダイヤ運転のシミュレーションで実際に列車が走り込みます

### 運転シミュレーション（運転タブ）

2つのモードがあり、どちらも**複数列車を同時に**走らせられます。

**入換（手動計画）**
- 「編成 → 行先」を計画に並べ、順に実行します
- 移動ごとに経路を探索し、**折返しで区切られた区間ごとに進路を構成 → 分岐器を転換 → 走行 → 折返し**を自動で進めます

**ダイヤ運転（時刻どおり）**
- シミュレーションの時計が**ダイヤの時刻**に同期し、**発車時刻になった列車から順に走り出します**
- 各列車は**走行計算にしたがって加減速**しながら走り、**中間駅にきちんと停車**します
  （停車中は到着番線に在線として表示され、ダイヤの発時刻になると次の駅へ発車）
  例：101M 06:00 西山発 → みどりが丘 06:03 発 → 東川 06:06 発 → 06:09 海岸着
- 通過駅は停車せずに走り抜けます（列車ごとに通過駅を設定できます）
- 発着番線・入庫先はダイヤの設定を使い、**入庫指定の列車は実際に留置線まで走り込みます**
  （回送が本線 → 引上線で折返し → 8番線へ、など）
- 同時運転の上限（既定6本）まで並行して走り、**進路が競合する列車は「進路待ち」**になります
  （閉塞信号機を増やして区間を分ければ、続行運転ができるようになります）

共通:
- 走行中の列車は図上を移動し、進路の帯・分岐器の開通方向・**信号現示がリアルタイムに連動**します
- 再生速度（×1〜×60）、入換速度、折返し時間、進路構成の所要時間、同時運転の上限を設定できます
- 実行ログに時刻つきで発車・進路構成・進路待ち・折返し・到着が記録されます

### 入換経路の検証（経路タブ）

線路の端点どうし・端点と他線の途中が近接していれば自動的に「接続」と判定し、基地全体の接続グラフを構築します。

- 対象編成（または両数）・起点・着点を選ぶと、**折返し回数が最小になる入換経路**を探索して図上にハイライト
- 着点には「◎ 場外へ出区（出入口）」も選べます
- 分岐の向きを考慮し、転向角が設定値（既定 90°）を超える進路は**折返しが必要**と判定
- 「現在の分岐器の開通方向に従う」を有効にすると、転換なしで進める経路だけを探索
- 折返しに使う線路の**有効長が編成長に足りない場合は警告**（引上線の長さ検証）
- 経由する線路に他編成が留置されていれば「支障」として警告、着点の留置可能両数超過も警告

### レイアウト検証

経路タブ下部に、レイアウトの不具合を一覧表示します（図上には赤／橙のマーカー、クリックでその場所へジャンプ）。

- どの線路にも接続していない**孤立した線路**
- 車止めも場外接続も設定されていない**未処理の端点**
- **場外（出入口）から到達できない線路**
- **線路中心間隔の不足**（既定 4.0m、設定で変更可）
- **接続点のない線路どうしの交差**（分岐器・クロッシングの不足）
- **建築限界の支障**（既定 片側 1.9m の範囲に建屋・ホーム・駐車場などが掛かっている）
- **構造物どうしの重なり**
- 留置両数が有効長を超えている線路

なお、プロパティの数値欄は入力中にパネルを作り直さないため、幅・奥行・直径・座標などを
キーボードでそのまま打ち直せます（小数も可）。

### 車両と編成

編成には**車種**を設定できます。車種ごとに標準の1両長と色・記号を持ちます。

| 車種 | 標準1両長 | 図上の表現 |
| --- | --- | --- |
| 電車（EMU） | 20m | パンタグラフ記号 |
| 気動車（DC） | 20m | 排気記号 |
| 客車 | 20m | 付随車（動力表現なし） |
| 貨車 | 14m | 付随車（動力表現なし） |
| 電気機関車（EL） | 18m | パンタ2基＋「EL」 |
| ディーゼル機関車（DL） | 16m | 排気＋「DL」 |
| 蒸気機関車（SL） | 20m | 煙突＋「SL」 |
| 保守用車 | 12m | 排気記号 |

- 客車・貨車などには**牽引機（EL／DL／SL、最大3両）**を付けられます。編成長・両数は牽引機を含めて計算されます
- 拡大すると1両ずつ描き分けられ、機関車は車体色と記号で区別できます
- 「＋ 電車／気動車/客車列車／貨物列車／機関車／保守用車」のボタンから、既定の構成で編成を追加できます

### 留置両数と編成

- 線路ごとに **留置可能両数**（自動算出 or 手入力）・**1両長の個別設定**
- **編成**を作成し、車種・両数・牽引機・形式・色・メモを編集、任意の線路へ割り当て
- 留置した編成は線路上に**車両1両ずつの帯**として描画され、有効長の超過は赤く警告（車種ごとに1両長が異なるため、超過判定は実長で行います）
- 「自動で留置線へ割付」で未留置編成を空き線に一括割当
- 基地全体の留置可能両数・留置中両数・使用率をサマリー表示

## 操作方法

| 操作 | 内容 |
| --- | --- |
| パレット → 線路種別 → クリック | 折線で線路を敷設（ダブルクリック／Enter／右クリックで確定） |
| パレット → 構造物 → クリック | 構造物を配置（Shift+クリックで連続配置） |
| ドラッグ | 選択中の線路・構造物を移動（空白部分のドラッグは画面移動） |
| ホイール | ズーム |
| 選択中の線路をダブルクリック | 折点を追加／折点上でダブルクリックすると削除 |
| 選択中の構造物の四隅をドラッグ | サイズ変更（Shiftで縦横比固定、Altでスナップ解除。分岐器は記号のため対象外） |
| 線路の交点をクリック | 分岐器（未接続の交差ならダイヤモンド／スリップ）を自動設置 |

ショートカット: `V` 選択 / `T` 線路 / `H` 画面移動 / `R` 45°回転 / `F` 全体表示 / `G` グリッド /
`Enter` 敷設確定 / `Esc` 取消 / `Delete` 削除 / `Ctrl+Z` 元に戻す / `Ctrl+Shift+Z` やり直し /
`Ctrl+D` 複製 / `Ctrl+S` JSON保存 / `Ctrl+O` 読込 / スペース+ドラッグ 画面移動

設定タブでグリッド間隔（既定 5m）、標準1両長（既定 20m）、線路端部の余裕長（既定 10m）、
線路中心間隔の最小値（既定 4.0m）、建築限界の片側幅（既定 1.9m）、転向角の上限（既定 90°）、
接続点・検証マーカーの表示、スナップや 45° 拘束の ON/OFF を変更できます。
